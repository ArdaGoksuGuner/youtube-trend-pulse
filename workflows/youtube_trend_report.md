# Workflow: YouTube AI/Automation Trend Report

## Objective
Produce a polished PDF summarizing the last ~14 days of trending content in the AI / AI automation niche on YouTube, and email it to the user. The PDF is generated locally using the canvas-design philosophy ("Signal in the Dark") — no Google Slides or Drive required.

## Required inputs
- `.env` populated:
  - `YOUTUBE_API_KEY` — Google Cloud API key with YouTube Data API v3 enabled
  - `ANTHROPIC_API_KEY`
  - `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`
  - `NICHE_QUERIES` — comma-separated search queries (default in `.env.example`)
- `credentials.json` at project root — OAuth Desktop client from Google Cloud (YouTube scope only)
- `token.json` — generated by `tools/setup_oauth.py` (one-time)

## One-time setup
1. Google Cloud Console → enable **YouTube Data API v3** on the project.
2. Create an **API key** → put in `YOUTUBE_API_KEY`.
3. Create an **OAuth client (Desktop app)** → download as `credentials.json` at project root.
4. Gmail → enable 2FA → create an **App Password** → put in `GMAIL_APP_PASSWORD`.
5. `pip install -r requirements.txt`
6. `python tools/setup_oauth.py` — completes the browser consent flow, writes `token.json`.

## Run order

| Step | Command | Purpose | Quota |
|---|---|---|---|
| 1 | `python tools/discover_videos.py --days 14` | Pull videos from niche searches + your subscriptions, hydrate stats | ~800–1,200 units |
| 2 | `python tools/analyze_videos.py` | Compute rankings, ask Claude for theme synthesis | 1 Claude call (~$0.05) |
| 3 | `python tools/generate_charts.py --style dark` | Render 6 PNG charts | 0 |
| 4 | `python tools/build_pdf.py` | Build canvas-design PDF report (14+ pages) | 0 |
| 5 | `python tools/send_report.py` | Email PDF as attachment with executive summary | 0 |

Total runtime: ~3 minutes. Total cost: ~$0.05 + free YouTube quota.

## Edge cases & known issues

**Quota exhaustion (403 quotaExceeded).** Each `search.list` is 100 units; eight queries = 800. If you re-run twice in a day, you can hit the 10K daily limit. Solutions:
- Wait until midnight Pacific Time (quota resets).
- Reduce `NICHE_QUERIES` count.
- Run with `--skip-subscriptions` to skip the per-channel searches.

**Subscriptions returns empty.** If `subscriptions.list?mine=true` returns nothing, the user has hidden their subscriptions in YouTube settings. Toggle "Keep all my subscriptions private" off, or run `--skip-subscriptions`.

**Claude returns malformed JSON.** `analyze_videos.py` has a robust regex extractor (`parse_json_from_text`). If it still fails, rerun the analyze step — the discover output is cached in `.tmp/videos_raw.json`.

**Gmail `SMTPAuthenticationError`.** The 16-char App Password must be entered without spaces. Regular Gmail passwords will not work (2FA required).

**Thumbnail download failures.** `build_pdf.py` downloads video thumbnails via `requests` and caches them in `.tmp/thumbnails/`. If a thumbnail 404s, the slot is left as a dark placeholder and the PDF still renders. Re-running the step will retry any missing thumbnails.

**Font missing warning.** If a `.ttf` file is absent from `.claude/skills/canvas-design/canvas-fonts/`, reportlab falls back to Helvetica for that font slot. Re-run `npx claude-code-templates@latest --skill creative-design/canvas-design` to restore the font pack.

**Niche tuning.** Edit `NICHE_QUERIES` in `.env`. Good additions: `"AI workflow"`, `"AI SaaS"`, `"vibe coding"`, `"Cursor AI"`. Avoid generic terms like `"AI"` alone — too noisy.

## Outputs
- `.tmp/videos_raw.json` — hydrated video records (regeneratable)
- `.tmp/analysis.json` — metrics + Claude synthesis (regeneratable)
- `.tmp/charts/*.png` — chart images (regeneratable)
- `.tmp/thumbnails/*.jpg` — cached video thumbnails (regeneratable)
- `.tmp/report.pdf` — **canvas-design PDF report** (main deliverable)
- `.tmp/quota_log.json` — quota usage log
- Email to `REPORT_RECIPIENT` (default: `GMAIL_ADDRESS`) — **second deliverable**

## Self-improvement notes
- If a step fails, fix the tool and rerun *only that step* — outputs of prior steps persist in `.tmp/`.
- When you discover better niche queries or smarter metric definitions, update `.env` and `analyze_videos.py` respectively. Capture the lesson in this workflow.
- The PDF design philosophy is "Signal in the Dark" — dark bg (#0a0a12), primary accent #7b9cff, secondary #c77dff. If the visual style needs adjustment, edit the color constants at the top of `build_pdf.py`.
